# My Roadmap — Kim Minsu Portfolio

Personal portfolio for `https://kiim-miin-su.github.io/github.io/`.

Static HTML, CSS, and vanilla JavaScript. No build step or secrets are required. To preview locally, run `python3 -m http.server 8000` here and visit `http://localhost:8000`.

## Publishing

This repository is currently named `github.io`. Publish the `main` branch from `/ (root)` in **Settings → Pages → Build and deployment**. The project site's address is `https://kiim-miin-su.github.io/github.io/`.

To use `https://kiim-miin-su.github.io/` as the main user site, rename the repository to `Kiim-Miin-Su.github.io` in **Settings → General**. After renaming, update the canonical and Open Graph paths in `index.html`, the canonical link in `resume.html`, and this README to the root URL.

Content was cross checked against the user's résumé, Study Notion, and public repositories on 2026-11-22. Educational entries intentionally avoid asserting a current enrollment status. Private contact details beyond the résumé's professional email are omitted. The public résumé is available as `resume.html` and supports browser print / PDF export.
